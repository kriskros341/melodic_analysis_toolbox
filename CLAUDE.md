## The analysis pipeline (big picture)

`melody.py` runs one per-track pipeline whose stages span several functions — read
them together to understand a feature, not in isolation:

1. **Tempo** — `compute_tempo_features`, then `fold_bpm_to_band` folds BPM *down only*
   by metric octaves (÷2) into a gait-cadence band (fixes the *alla breve* doubling of
   marches without inflating genuinely slow pieces).
2. **Lead voice** — `build_rolls` → `pad_rolls` → `compute_highest_per_instrument` →
   `track_lead_voice` extract one melodic line across beat-aligned windows.
3. **Melodic features** off the lead voice — contour, pitch classes, key
   (`compute_key_from_pitch_classes`), phrases (`segment_phrases`), motifs.
4. **Rhythm/form features** — `compute_ioi_features`, `compute_pulse_clarity`
   (autocorrelation of the onset envelope), `compute_syncopation`,
   `compute_form_complexity` (self-similarity matrix).
5. **Aggregation** — `compute_feature_vector` bundles everything into a dict;
   `feature_vector_to_array` flattens to a numeric vector that *includes a 12-dim
   pitch-class histogram*.
6. **RAS index** — `compute_entrainment_suitability` = geometric mean of
   (cadence fit × pulse clarity × (1 − syncopation)); any zero term zeros the result.

**Non-obvious decision:** clustering in `4_comparison.ipynb` uses **only a 7-feature
rhythmic/formal subset**, *not* the full `feature_vector_to_array` output — the 12-dim
pitch-class histogram otherwise dominates the standardized distance and groups pieces
by key instead of function. Keep that subset if you touch the clustering.

## Report build (`report/`)

The report is Typst (`report/raport.typ`) using the `ilm` template, with a Hayagriva
bibliography in `report/refs.yml`. Figures in `report/figures/*.png` are **generated by
executing `4_comparison.ipynb`** (each plotting cell does `plt.savefig("report/figures/...")`).

- `make fetch` — download the Fira Mono fonts the template needs into `.fonts/` (run once).
- `make report` — compile to `report/raport.pdf` (`typst compile --font-path .fonts ...`).
- `make watch` — live recompile while editing.
- Regenerate figures after changing the analysis:
  `uv run --with nbconvert --with ipykernel jupyter nbconvert --to notebook --execute --inplace 4_comparison.ipynb`

Rebuilding the report from scratch = run notebook 4 (figures) → `make report`.
